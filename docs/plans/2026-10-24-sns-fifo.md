# SNS FIFO topics

Implement FIFO topic creation, immutable topic type, content-based deduplication,
and topic or message-group deduplication scope. Support ordered fanout to SQS
FIFO and standard queues, including raw delivery, filters, and batch publishing.
Return sequence numbers for FIFO publishes and include them in envelopes.

Keep topic definitions persistent. Keep deduplication and sequence state in
memory, like SQS messages. Serialize FIFO publishes through delivery without
holding the topic state mutex while calling SQS.

Validate with engine tests, AWS SDK end-to-end tests, race tests, and existing
AWS golden replay. Add dedicated AWS differential scenarios for FIFO topics.
New AWS recordings require maintainer authorization and credentials. Do not
claim AWS parity until those recordings replay successfully.
